# Database Rules

- Использовать Prisma + PostgreSQL.
- Схему менять через миграции.
- После изменений запускать `npx prisma format`.
- После форматирования запускать `npx prisma generate`.
- Не использовать `prisma db push` в боевой среде.
- Не сбрасывать базу без явного разрешения.
- Не использовать raw SQL.
- Денежные суммы хранить целыми копейками.
