# Frontend Rules

- Использовать Next.js App Router.
- Server Components по умолчанию.
- Client Components только для интерактивности, browser API и локального состояния.
- TypeScript strict обязателен.
- Переиспользовать компоненты вместо огромных `page.tsx`.
- Для маршрутов нужны loading, error и empty states.
- Использовать `next/image` для продуктовых и внешних изображений.
- Не делать один огромный файл страницы.
