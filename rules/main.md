# 88Shops Main Rules

- Проект называется 88Shops.
- Не использовать Origo или Aurora.
- Не ломать существующий код и сначала читать текущую реализацию.
- Делать маленькие осмысленные изменения.
- Все исходники хранить в UTF-8 без mojibake.
- После изменений запускать `npx tsc --noEmit`, `npm run lint` и `npm run build`.
