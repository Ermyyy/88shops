# Payments Rules

- Финансовые функции показывать только со статусом "Скоро", пока интеграция не подключена.
- Реальные платежи не подключать.
- QR не генерировать.
- СБП не подключать.
- `PaymentProvider` не добавлять без реальной реализации.
- Webhook должен проверяться на сервере.
- Клиент не подтверждает оплату и не меняет финансовые статусы.
- Не хранить карты.
- Не принимать и не удерживать средства до запуска платежной интеграции.
