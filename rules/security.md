# Security Rules

- Все формы валидировать через Zod.
- Права и приватные действия проверять на сервере.
- Не хранить секреты в репозитории.
- Не хранить платежные данные.
- Загрузки файлов валидировать по MIME и размеру.
- Для будущих route handlers предусматривать rate limiting.
- Не показывать stack trace пользователю.
- Финансовый статус меняет только сервер.
